1. Abre index.html para ver la página.
2. Reemplaza las imágenes dentro de la carpeta images:
   - logo.png
   - fondo-agua.jpg
   - auto.png
   - suv.png
   - pickup.png
   - detailing.jpg

IMPORTANTE:
Las rutas del HTML ya están preparadas para funcionar cuando subas TODA la carpeta a GitHub Pages.

Para publicar:
- Crea un repositorio en GitHub.
- Sube index.html y la carpeta images.
- Ve a Settings > Pages.
- Selecciona Deploy from a branch.
- Branch: main
- Folder: / (root)
- Guarda.

Después GitHub te dará un enlace público para abrir la página desde cualquier dispositivo.
